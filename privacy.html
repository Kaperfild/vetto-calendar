Политика конфиденциальности

Vetto Calendar – личный инструмент одного владельца. Доступ к Google Calendar и YouTube он получает только от аккаунта владельца и только с его согласия.

Данные (события календаря, список и субтитры видео канала) используются только на компьютере владельца для его собственного расписания и учёта видео. Они не передаются третьим лицам, не продаются и не используются для рекламы.

Доступ можно отозвать в любой момент в настройках аккаунта Google: myaccount.google.com/permissions.

Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.
